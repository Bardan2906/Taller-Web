# Asistente del Dungeon Master

Aplicacion de apoyo para partidas de Dungeons and Dragons 5e con bestiario, generador de botin y bandeja de dados. Usa la API https://www.dnd5eapi.co/api/

link github: https://github.com/Bardan2906/Taller-Web.git

Despliegue en Vercel: https://web-two-wine-22.vercel.appgit add README.md

## Comandos

    npm install
    npm run dev
    npm run build

## Android

    npx cap add android
    npm run build
    npx cap sync
    npx cap open android
